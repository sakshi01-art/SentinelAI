# SentinelAI

## Educational Security Monitoring Project

SentinelAI is a beginner-friendly project for visualizing and organizing security events in a clean dashboard.

### Planned Features
- Event dashboard
- Risk status display
- Explainable alerts
- Event history
- Documentation

### Project Structure

```text
SentinelAI/
├── backend/
├── frontend/
├── docs/
├── README.md
├── CONTRIBUTING.md
└── LICENSE
```

> This project is intended for educational and defensive security learning.
